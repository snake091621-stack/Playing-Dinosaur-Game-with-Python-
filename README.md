Playing Dinosaur Game with Python🐍🦖

This program plays the dinosaur game itself without you playing or even touching the keyboard.

First, open Google (with the internet turned off) and bring up the dinosaur game, then place the mouse at the appropriate coordinates and you will see the dinosaur jumping over the cacti.
